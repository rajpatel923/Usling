# devlog — Pair Companion Knowledge Log

One compressed entry per session or significant task. Entries are written by the coding agent at the end of each work session.

## Entry format

```
# [NNN] Title
Date: YYYY-MM-DD  Phase: V1 | V1.1 | V2  Week: N
## What
One-paragraph summary of what was built or changed.
## Why
The product or technical motivation.
## Key decisions
Bullet list of non-obvious choices made.
## Files touched
Key paths (not exhaustive).
## Next
What logically follows.
```

## Naming

`NNN-slug.md` — three-digit zero-padded sequence, kebab-case slug.
